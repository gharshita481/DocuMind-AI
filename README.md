# DocuMind AI – Research Paper Intelligence Platform

An NLP-powered platform designed to simplify research paper analysis using AI, semantic search, and Retrieval-Augmented Generation (RAG).

## Key Features
- Multiple PDF Upload and Processing
- Intelligent Question Answering
- Semantic Search
- FAISS Vector Database
- Research Paper Summarization
- Research Insights Extraction
- Keyword Extraction and Analytics
- Conversational AI
- Interactive Gradio Dashboard
- Chat History Management

## Tech Stack
- Python
- NLP
- Sentence Transformers (MiniLM)
- FAISS
- FLAN-T5
- PyMuPDF
- Gradio
- NumPy
- SQLite
- Google Colab

## Project Files
- `DocuMind_AI.ipynb` – Complete Google Colab notebook.
- `DocuMind_AI.py` – Python source code.
